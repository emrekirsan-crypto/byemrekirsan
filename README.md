# byemrekirsan.com

Emre Kirsan'ın kişisel sitesi. Saf HTML, CSS ve JS, derleme adımı yok.

## Sayfalar
- `index.html`: Ana sayfa (EN / TR / DE). Metinler dosyanın altındaki `const T = {...}` bloğunda.
  - "Şu an" satırı (`now.l` / `now.v`): Ayda bir güncelle, üç dilde de.
  - Yazılar listesi: Hakkımda bölümünün altında, Medium bağlantıları.
- `check.html`: "İşiniz nerede tıkanıyor?" testi. 7 soru, skor, rota haritası, 3 öneri. Cevaplar tarayıcıda kalır.
- `example-case-study.html`: Herkese açık örnek çalışma (kurgusal, sayfada öyle belirtiliyor).
- `case-study-template.html`: Boş proje şablonu. Kopyala, doldur, `noindex` satırını sil.
- `404.html`: "Yanlış sapak" sayfası. Netlify bulunamayan adreslerde otomatik gösterir.

## Diğer
- `fonts/fonts.css`: Yazı tipleri dosyanın içine gömülü (Anybody, Hanken Grotesk, Martian Mono · SIL OFL).
- `favicon.svg`, `apple-touch-icon.png`, `og.png`: İkonlar ve paylaşım görseli.
- `brand/`: Logo dosyaları ve `imza.html` ("made byemrekirsan.com" kodları).
